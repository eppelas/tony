# Агентный режим

Учебный статический дашборд об агентной работе: контекст, проектная память, разрешения, API/MCP, skills, Git/GitHub, голосовой ввод и когнитивная нагрузка.

## Что внутри

- карта ключевых концепций;
- понятные определения API, MCP, skill, Git и GitHub;
- примеры агентных сценариев;
- домашка для новичка с готовыми промптами.

## GitHub Pages

Сайт не требует сборки. Workflow `.github/workflows/pages.yml` публикует статические файлы через GitHub Actions после каждого push в `main`. Все публичные пути относительные.
