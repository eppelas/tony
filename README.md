# Агентный режим

Публичный статический дашборд по материалам 57-минутного диалога об агентной работе: контекст, проектная память, разрешения, API/MCP, skills, Git/GitHub, голосовой ввод и когнитивная нагрузка.

## Состав

- index.html — структура страницы;
- styles.css — editorial paper-machine visual system;
- app.js — рендеринг, фильтры, поиск, прогресс домашки и копирование промптов;
- data/dialogue.json — обезличенные концепции, инструменты, определения, сценарии, домашка и таймлайн;
- .nojekyll — публикация корня без обработки Jekyll.

Полный транскрипт, суммаризация, исходное аудио и локальные пути не публикуются.

## Локальный просмотр

Дважды кликните ! Open Agent Mode Preview.command или _ Agent Mode Preview.app.

Launcher:

1. проверяет, свободен ли порт;
2. переиспользует только сервер этого проекта;
3. при необходимости выбирает следующий свободный порт;
4. слушает 0.0.0.0 для просмотра с телефона в локальной сети;
5. отдаёт только публичный allowlist: HTML, CSS, JavaScript, обезличенный JSON и шрифты;
6. возвращает 404 для transcript.txt, summary.txt, homework.txt и других локальных файлов;
7. печатает localhost и LAN URL.

## GitHub Pages

Сайт не требует сборки. Публикация выполняется из ветки main, директория / (root). Все публичные пути относительные.

## Приватность

В публичный JSON не входят медицинские или терапевтические детали, адреса, данные аккаунтов, криптокошельки, приватные пути и полная стенограмма.
